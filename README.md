# نظام الاستبيانات الورقية الموحّد

يجمع هذا المجلد بين:

1. محرك توليد القوالب الأصلي المكتوب بـ HTML/CSS/JavaScript داخل هذا المشروع.
2. ملف `omr.py` الأصلي لمعالجة صور الاستبيانات واكتشاف الإجابات.
3. واجهة موحدة لرفع الأوراق ومراجعتها وحفظ النتائج وتصدير CSV/JSON.

## التشغيل

ضع ملف `omr.py` الأصلي بجوار `app.py` أو في المجلد الأب له. في بنية ملفات المحادثة الحالية، `omr.py` موجود في المجلد الأب بالفعل.

يتطلب Python 3.10 أو أحدث. ثبّت متطلبات Python:

```bash
python -m pip install -r requirements.txt
```

تأكد من وجود Node.js 22 أو أحدث ومتصفح Chrome أو Edge أو Chromium، ثم من داخل هذا المجلد شغّل:

```bash
python app.py
```

يفتح البرنامج تلقائياً على:

```text
http://127.0.0.1:5000
```

هذا هو أمر التشغيل الوحيد. Flask يخدم الواجهة الموحدة ويمرر طلبات المعاينة والتوليد إلى محرك JavaScript المحلي عبر Node.js؛ ولا يشغّل خادماً ويب ثانياً. عند معالجة الصور يستدعي `app.py` الدالة `omr.process()` من `omr.py` الأصلي.

## تبويبات البرنامج

- **تصميم القالب:** يعرض واجهة المحرك الموجود في `index.html` و`app.js`. يمكن ضبط حجم خط السؤال والخيارات بالـ pt وهوامش الصفحة بالـ mm من شريط تمرير أو إدخال رقمي؛ وتستخدم المعاينة والتصدير القيم نفسها. يبقى السؤال كتلة واحدة ولا يُقسّم بين الصفحات. المعاينة والتصدير تنفذهما وحدات JavaScript في `src/`.
- **رفع ومعالجة:** يقبل ملفات الصور وPDF ويشغّل `omr.py` على الملفات المرفوعة.
- **المراجعة:** يعرض صور كل ورقة، والاختيارات المكتشفة ودرجات الحبر، ويسمح بتعديل الاختيارات وإدخال إجابات الأسئلة النصية يدوياً ثم حفظها.
- **النتائج:** يعرض الإجابات المحفوظة ويصدرها إلى CSV أو JSON.

## المجلدات والملفات الناتجة

- `survey.current.json`: آخر استبيان تم توليده، مع بقاء `survey.json` كملف مثال أصلي.
- `template/`: ملفات القالب المولّدة (`survey.pdf`, `p1.png`, ... و`layout.json`).
- `work/`: صور الأوراق المحاذاة وبيانات المراجعة التي ينشئها `omr.py`.
- `output/`: نتائج الأوراق المراجعة و`all.json`.

لا تعدّل `omr.py` خوارزمية اكتشاف العلامات أو حساب درجات الحبر. يجب الحفاظ على ملفات PNG و`layout.json` المولّدة معاً؛ لأن OMR يقرأ الصور ومراكز علامات الزوايا والمستطيلات من القالب.

## متطلبات Python

- Flask لتشغيل واجهة التطبيق الموحدة.
- NumPy وOpenCV كما يتطلبهما `omr.py`.
- PyMuPDF اختياري، ولا يلزم إلا عند رفع ملفات PDF للمسح.

## توليد مستقل (اختياري)

يمكن تشغيل محرك JavaScript واختباراته دون واجهة OMR:

```bash
npm test
npm run generate -- survey.json template
```

## اختبار التكامل

نفّذ `npm test` لاختبارات المحرك والتخطيط، ثم `python tests/test_omr_integration.py` لاختبار التكامل مع `omr.py` الأصلي: اكتشاف علامات الزوايا، محاذاة الصفحة، والتعرف على دائرة سوداء تجريبية في منطقة خيار. يستخدم الاختبار مجلداً مؤقتاً ولا يغير بيانات عملك. تفاصيل النتائج وحدود الاختبار في `TEST_REPORT.md`.
