## اختبار التكامل

أُضيف مسار CI ثالث يقوم بتوليد القالب عبر Chromium ثم يشغّل `tests/test_generated_template.py`. يتحقق هذا الاختبار من توافق PDF وPNG مع `layout.json` ويضع علامة اصطناعية داخل خيار ليتأكد من قراءة OMR لها.

في تشغيل GitHub Actions رقم 21، نجح `npm run generate` ونجح الاختباران المتكاملان: أبعاد PDF/PNG وعلامات الزوايا، ثم قراءة OMR لخيار محدد اصطناعياً. وقع هذا التشغيل قبل تعديل آلية اتصال Chromium، لذلك يجري إعادة تشغيله على أحدث نسخة من محرك المتصفح الذي يستخدم منفذاً محلياً محجوزاً مسبقاً بدلاً من انتظار ملف `DevToolsActivePort`.

## التشغيل المحلي

```bash
npm test
npm run test:python
python -m py_compile app.py omr.py
npm run generate
python -m unittest discover -s tests -p "test_generated_template.py" -v
```

اختبار توليد PDF يتطلب Node.js 22 أو أحدث ومتصفح Chrome أو Edge أو Chromium. اختبارات Python تتطلب NumPy وOpenCV.

## حدود الاختبار

حتى بعد نجاح اختبار التكامل، فهو يستخدم علامة اصطناعية مرسومة على صورة مولدة، وليس ورقة مطبوعة أو تصويراً بكاميرا/ماسح حقيقي. قبل اعتماد تغييرات الإحداثيات في الإنتاج، ينبغي تنفيذ تجربة طباعة ومسح حقيقية وفحص PDF بصرياً.

## الثوابت

- كل سؤال وخياراته وحدة واحدة ولا يتم تقسيمه بين الصفحات.
- `omr.py` يبقى كما هو ما لم يطلب المستخدم صراحة تعديله.
- أي تعديل في تخطيط الورقة يجب أن يحافظ على التطابق بين PNG و`layout.json`.
